Device Temperature Monitoring Program

Project Description

The Device Temperature Monitoring Program is a simple Python project developed for a Computer Engineering laboratory. It monitors simulated device-temperature readings, classifies each reading, calculates numerical summaries, and determines the overall device status.

Objectives

- Store and manage temperature readings.
- Accept additional valid temperature readings.
- Classify readings according to the given temperature ranges.
- Calculate the minimum, maximum, average, and other required numerical summaries.
- Determine the overall status of the device based on the temperature readings.

Features

- Temperature Classification: Classifies each reading according to the specified temperature rules.
- Input Validation: Checks whether additional readings are valid before accepting them.
- Statistical Summary: Computes the required numerical summaries of the readings.
- Device Status: Determines the overall device status based on the given rules.
- Modular Programming: Uses functions to organize the program into smaller, manageable parts.

Requirements

- Python 3
- A code editor, such as Visual Studio Code, or a Python IDE

How to Run the Program

1. Download or clone this repository.

2. Open the project folder in your code editor or terminal.

3. Run the following command:
   
   python device_monitor.py

4. Follow the instructions displayed by the program.

Initial Data

The program starts with the following temperature readings:

readings = [28, 31, 35, 37, 29]

Additional valid readings can be entered while the program is running, depending on the program's implementation.

Testing

The program is tested using different temperature readings, valid and invalid inputs, and the required numerical calculations. The actual test cases and their results are documented in "test_cases.md".
